# ADME-Tec

Interactive platform for ADME analysis, prediction, and visualization of chemical compound

## Installation

ADME-Tec can be installed and launched from streamlit using a conda enviroment. There may be some differences depending on the OS, however the software has been tested for both Windows and Linux.

To create the conda enviromment run the following command
```bash
conda env create -f environment.yml
```
In case of broken dependencies of python modules, one can use the requirements of just admet-ai version 1.3.1 which can be found on the repository of the library and this enviromment also needs svglib version 1.5.1

## Usage

Run the app:

```bash
streamlit run ADME-Tec_app.py
```
